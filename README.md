# Pain OS

Pain OS is a lightweight Linux distribution based on Linux From Scratch and Nanolinux. It is designed to be minimalistic, efficient, and user-friendly, providing a solid foundation for users who want to build their own custom Linux environment.

## Features

- Based on Linux From Scratch and Nanolinux
- Lightweight and minimalistic design
- Customizable and extensible
- Suitable for both beginners and advanced users

## Getting Started
To get started with Pain OS, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/shm0m/pain-os.git
   ```

2. Execute the iso file with qemu:
   ```bash
   qemu-system-x86_64 -cdrom iso/painos.iso -m 512
   ```  

3. Have fun exploring Pain OS!
